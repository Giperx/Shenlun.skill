# Shenlun Master — 申论备考训练 Skill

> 多位名师，多种解法——从材料提炼观点，把观点写成有说服力的论证

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Agent: Skill](https://img.shields.io/badge/Agent-Skill-orange.svg)](https://github.com/Giperx/Shenlun.skill)
[![题型](https://img.shields.io/badge/题型-小题·大作文-blue.svg)](#题型速查)

**小题参照白鹭与小马哥，大作文融合饮冰说申论与袁东**：饮冰用于总分论点提取、四法论证及段落改写，袁东提供结构工具与教学估分。

融合多位名师**有据可溯**的方法论，以申论命题人和阅卷人视角严格评判作答。
支持**文字与图片双输入**：试卷照片、题目截图、手写作答照片可直接发送，模型原生识读。

本仓库是 [Giperx/Shenlun.skill](https://github.com/Giperx/Shenlun.skill)，基于 [coffe-d/Shenlun.skill](https://github.com/coffe-d/Shenlun.skill) 持续改进的大作文教学版本，保留上游小题能力与原作者署名。

> **给的是建议，不是判决。** 同一道题摆开不同解法供对照，帮你在比较中形成**适合自己的那一套**做题方法论。

## 快速开始

### 什么时候用？直接开口就行

| 你说 | 触发 |
|---|---|
| "帮我批改这道对策题" | 小题批改（双视角作答 + 阅卷人评分） |
| "这道综合分析题从小马哥和白鹭角度各给一版" | 双视角参考作答 + 差异对照 |
| "这道大作文帮我看看有没有偏题" | 对照题干材料判断，按需教学估分 |
| "从这些材料找总论点和分论点" | 题干关系→材料启示→机制→论点及依据 |
| "按饮冰的四种方法论证这个分论点" | 组合、政府思维、否定之否定、量变与质变，按证据选法 |
| "把别人这段论证适配到我的分论点" | 固定观点与事实，重建推理并成段改写 |
| "了解乡村振兴话题，有哪些参考论点" | 按需检索话题卡，提供候选判断、机制与证据条件 |
| "我写的这篇作文怎么样"（没给题干） | 先索取原题，拿不到则转通用评改 |
| "我只想改语言，别挑错别字" | 按表述升级规则给替换建议 |
| "我的老毛病是什么""最近进步了吗" | 读错题库给短板诊断 |
| "我准备 2026 国考地市级" | 命题预判 |

**不用记任何命令。** 发题目、发作答、发图片都可以——路由器会自动分派到对应技能。

## 效果示例

> ⚠️ **以下为示意示例**（用于说明输出形态），**不是真实批改记录**。
> 真实批改会按你的具体题目与作答给出，内容随题而变。

**一次批改的输出构成**（小题为例；整篇大作文可参照类似反馈，评分时标注教学估分口径；局部任务只交付所需内容）：

| # | 输出 | 说明 |
|:--:|---|---|
| ① | 真题识别结果 | 试卷／题号／题型／分值／原题 |
| ②③ | 双视角参考作答 | 小马哥版（结构固定、要素融合）＋ 白鹭版（结构随题干、要素分栏）——**两版结构性不同**，不是换措辞 |
| ④ | 差异对照 | 各自多踩/漏了哪个采分点 · 分类逻辑差异 · 适用场景 · 各自风险 · "你更适合哪一套" |
| ⑤ | 阅卷人评判 | 采分点逐条核对 + 总分（用题目实际分值，非百分制） |
| ⑥ | 改进建议 | 五段式：失分点 → 表述升级 → 成语与名言 → 论证思路 → 优化示范（**只讲怎么改，不做诊断**） |
| ⑦ | 复发提醒 | 某失分点类型累计 ≥2 时，指出"这是第 N 次"及上次在哪道题 |

### 场景一：提交小题作答要批改

```
用户 ❯ 帮我批改这道归纳概括题。作答：当前基层治理主要有四方面问题：
一是执法方式简单粗暴；二是公共服务设施不完善，停车难；三是流动摊贩管理
反复；四是过度依赖技术手段，忽视群众实际需求。

skill ❯ 【真题识别结果】未匹配到真题库 → 按通用评估标准

【参考作答 · 小马哥版】              结构固定、要素融合
　基层治理存在四方面短板。
　一、执法方式粗放。执法简单粗暴，缺乏规范标准。
　二、公共服务供给不足。停车、如厕等设施不完善。
　三、长效机制缺失。流动摊贩管理陷入"整治—反弹"循环。
　四、技术应用失当。过度依赖技术手段，忽视群众实际需求。
　（统一句式的动宾概括词，举措与成效融合在一条内）

【参考作答 · 白鹭版】                结构随题干、要素分栏
　一、执法：方式简单粗暴 → 缺乏规范标准
　二、设施：停车如厕难  → 公共服务供给不足
　三、管理：整治反复    → 长效机制未建立
　四、技术：依赖技术    → 群众需求被忽视
　（把材料要素拆成两栏逐条配对——与上版【结构性不同】，不是换措辞）

【差异对照】
　· 小马哥版"问题+实质"融合，读来干练，适合要点密集、字数紧的题
　· 白鹭版"现象/本质"分栏，层次清晰，但条数偏多、吃字数
　· 本题 200 字上限 → 小马哥版更省字；字数宽裕时白鹭版更易被阅卷人找到对应关系
　· 落点：写不长、易堆字 → 先学小马哥；常被说"层次不清" → 学白鹭

【阅卷人评判】采分点覆盖 4/4（执法规范／设施短板／长效机制／技术应用）　总分 14/20

【改进建议】
　· 表述升级："执法方式简单粗暴"→"执法方式粗放"（更书面，且与"规范标准"呼应）
　· 论证思路：问题类答案可给每点补一个"影响"，体现分析深度
　· 优化示范：原文"三是流动摊贩管理反复"→"三、长效机制缺失。摊贩管理陷入
　　'整治—反弹'循环，缺乏常态化机制。"

【复发提醒】
　⚠️「B1-无统一句式」这是第 2 次了。
　上次在《XX 题》也犯过（各条概括词字数从 4 字到 9 字不等，结构不齐）。
　建议专项训练：每条概括词统一为「动词+宾语」四字式，写完横向比一遍字数与结构。
```

### 场景二：提交大作文

```
用户 ❯ 帮我批改这篇大作文（附手写作答照片）。标题《以"三化"破局预制菜困局》

skill ❯

【图片识读结果】已转写正文约 950 字（请复核标题与分论点句）
【主题类型】单主题（预制菜产业发展）→ 三个分论点按维度展开
【文体】议论文（对策 + 影响）
【四类文判定】
　① 是否跑题：否
　② 框架：标题、开头（前+后）、总论点、分论点均正确 → 至少三类文
　③ 开头结尾：开头用排比句式引入，结尾回扣标题"便捷与安心" → 进二类
　④ 分论点论证：三段结构为「价值定位 → 问题诊断 → 分层对策」，
　　有"标准是产业发展的度量衡，也是保障安全的防火墙"这类有效论证 → 进一类
【评分】一类文（下档）
【改进建议】
　· 第 2 段案例只"举"未"证"——补一句机理：通过什么手段 → 解决什么 → 达到什么效果
　· 影响未做层级跃升：可尝试 微观（个人）→ 中观（企业/组织）→ 宏观（国家）
　· 表述升级："打造品牌" → "以品牌化赋能，实现从'产品思维'到'品牌思维'的转型"
```

### 场景三：只给作答、没给题干

```
用户 ❯ 帮我改一下这篇作文（附图），写得怎么样？

skill ❯

【缺题干】无法判断是否扣题、分值字数，先向你索取原题：

　为了精准评判，能否提供原题题干？两种方式都行：
　1. 直接说哪年、哪场考试、第几题（如"2023年国考地市级第5题"）
　2. 或把原题文字发给我
　顺便告诉我这道题多少分（大作文通常 35 或 40 分）。

—— 若确实提供不了，则转「通用文章评改模式」：

　· 不套真题采分点，改按一篇议论文评
　· 只评文章内在自洽：论点是否明确、论点与标题是否一致、论据是否支撑论点、
　　论证是否连贯
　· 不输出"立意判定：准确/偏题"（无题干时无从判断）
　· 五维评分：论点明确性 25% + 论据贴合度 30% + 结构条理 20% +
　　语言表达 15% + 卷面分 10%
　· 结果标注为35/40分制教学估分；纯文本不评字迹，无卷面依据时只报内容分或注明内容等比例估分
```

## 题型速查

| 题型 | 识别关键词 | 主力方法论 | 常见分值 |
|---|---|---|---|
| **归纳概括** | 概括/梳理/总结/提炼 + 问题/原因/做法/经验/成效/**变化**/特点 | 小马哥（结构固定、要素融合）· 白鹭（结构随题干、要素分栏） | 10–20 |
| **综合分析** | 分析/理解/评析/认识/看法/谈谈为什么 | 白鹭（按题干/句子成分拆解）· 小马哥（是什么→为什么→怎么办，**非强制**） | 15–20 |
| **对策启示** | 提出/建议/对策/启示 | 三种来源：概括对策 → 借鉴对策 → 提出对策 | 15–20 |
| **公文写作** | 写一份/起草/拟写 + 文种 | 格式要素（标题/称谓/落款）+ 内容按文种目的筛选 | 20–25 |
| **大作文** | 大作文/找论点/分论点论证/改写/文章写作 | 饮冰：材料提炼与四法论证；袁东：可选结构、教学估分 | 35–40 |

> **两条通用硬规则**（两位名师、16 份真题样本验证）：
> **归纳概括类不写总括句；综合分析类必须写总括句。**

## 架构与安装

### 多位教师怎样配合

小题保留白鹭与小马哥的对照作答；大作文新增饮冰讲义支持的材料提炼和四种论证方法，保留袁东结构与估分工具。按题意、证据和用户任务选择，不把各体系步骤叠加为固定流程。

不同写法确有差异才对照；最终看观点是否回应题意、证据是否支持结论、结构是否自洽。教学估分是训练参考，不是官方阅卷分数。

### 为什么拆成三个 skill

为了**按需加载**——小题任务不必加载大作文的整套方法论，反之亦然。

| 目录 | 职责 |
|---|---|
| `shenlun-router` | 输入、任务识别、考试题匹配与错题库 |
| `shenlun-xiaoti` | 归纳概括、分析、对策、公文及双视角作答 |
| `shenlun-dawenti` | 论点提取、四法论证、段落改写、整篇写作与教学估分 |
| `shared` | 三者共用的规则与导出脚本，不是独立技能 |

入口只加载当前任务需要的方法库，小题和大作文互不加载对方整库。

### 安装

需 Python 3。克隆本 fork 后执行；已下载压缩包的用户在解压后的仓库根目录从安装命令开始：

```bash
git clone https://github.com/Giperx/Shenlun.skill.git
cd Shenlun.skill

# 独立复制到 Codex 的技能目录，包含 shared 共用资源
python3 _tools/install_skills.py

# 自己维护 fork 时，用链接跟随本仓库更新
python3 _tools/install_skills.py --mode link

# 其他支持 SKILL.md 的 agent：指定其技能根目录
python3 _tools/install_skills.py --dest /path/to/agent/skills --mode copy
```

安装器先检查全部目标，已有同源链接会跳过，遇到其他同名目录则停止，不覆盖用户文件。复制模式更新时请自行核对旧目录后再安装；链接模式要求保留仓库位置。Windows可优先使用无需创建符号链接的复制模式。

也可以手动复制 `skills/` 中的**三个技能目录及 `shared`**到同一个技能根目录；三个技能各自作为直接子目录，保留其相互位置。只复制大作文目录会丢失共享资源。`shared` 无 `SKILL.md`，不会作为独立技能触发。

已安装并链接到本仓库的技能会直接使用文件更新；若客户端仍显示旧描述，重新加载技能或开启新会话。使用大作文方法库无需小红书登录、原PDF或作者电脑路径。

## 功能模块

### 错题库（长期能力追踪）
- **批改后自动记录**：每次批改把失分点按**类型**归入使用者本地的 `错题库/`
- **记类型，不记具体错误**：记的是"`B1-无统一句式`"这类可跨题比较的失分点类型，而不是"某题漏了某个采分点"——只有类型才能累积计数、看出复发模式
- **频次与状态**：🟡 初现（1 次）→ 🟠 复发（2 次）→ 🔴 顽固（≥3 次）
- **复发主动提醒**：同一失分点类型再次出现时，**主动提示"这是第 N 次"并指出上次在哪道题也犯过**；顽固项给**专项训练方案**
- **可查询**：问"我老毛病是什么""最近进步了吗"，按顽固→复发→初现排序输出，并明确指出已改善的项
- 分类体系（8 维度 · 细粒度编号）见 `skills/shared/references/error-bank-rules.md`；`错题库/` 已 gitignore，**个人数据不上传**

### 图片输入（原生支持）
- **直接用图片出题**：试卷照片、题目截图、材料扫描件、手写作答照片都可以直接发送，无须先转写成文字，也无须外接读图工具
- 图片识读规范：图片类型清点 → 结构化提取（题号/分值/字数/题干/材料）→ 模糊处标注自检 → 转写确认 → 无法识读时才降级
- **分值、字数限制、题号是评分基准**，识读时会主动向用户复核，读不准就标注 `[图像模糊]` 而不猜测
- 支持多图（多页试卷按页序拼接）、图文混合（冲突时以图片为准）、印刷体与手写体区分
- 只要所用 agent 与所选模型**支持图像输入**即可使用，不依赖任何外部读图工具或 MCP

### 真题识别
- 提交内容后**联网搜索 + 真题库双通道匹配**，自动定位考试年份、试卷类型、题号、原题
- 匹配成功后以真实阅卷采分点为评分基准，跳过通用推断
- 每次批改后自动入库，真题库渐进式扩充（`skills/shenlun-xiaoti/references/real-exams/`）

### 小题训练（`shenlun-xiaoti`）
- **双视角参考作答**，且**两版结构性不同**（不是换措辞）：
  - **小马哥版**：结构固定、要素融合——一律「上位概括词 + 具体做法」
  - **白鹭版**：结构随题干、要素分栏——题干有几个要素/对象/主体就分几栏（问"变化"用过去/现在对比；问"举措及成效"则配对）
- **差异对照五项**：各自多踩/漏了哪个采分点、分类逻辑差异、各自适用场景、各自风险、**"你更适合哪一套"**
- **诚实边界**：某些环节两版其实一致（如总括句有无、概括词需统一句式）会**直说"此处两版一致"**，不凑对照
- 评分 = 采分点覆盖法（子项逐条核对），使用题目实际分值

### 大作文训练（`shenlun-dawenti`）

- **论点提取**：判断题干能否直接拆解；再到重点材料提取概念或故事启示，必要时扩展其他材料；保留限定与关系，给出证据追溯。
- **四法论证**：组合论证补上证据到观点的桥梁；政府思维配对成绩、问题与措施；否定之否定明确保留与修正；量变与质变说明积累机制和模式变化。
- **改写适配**：固定论点和已知事实，先修推理再润色；拟议措施、推论与已有成绩分清，不移植原例统计数据。
- **方法融合**：并列与纵向结构均按实际证明任务评价；AB/ABC作为题意适合时的结构工具，不是所有题目的强制入口。
- **任务边界**：找论点只给论点，改段落只改段落；无需为了局部改写索要完整试卷。要求判扣题和整篇估分时才补题干。
- **教学估分**：袁东四类文保留并标明来源；无题干只评内部自洽，文本不猜字迹。教师例文与第三方材料不记入个人错题。
- **话题参考库**：九类83个话题入口，另有36条独立编写的候选判断及证明条件；用于认识话题和选择思路，不能替代题干材料或当作命题预测。第三方参考书与饮冰方法分别标明来源；另附141页按话题分页的OCR，安装者可直接查阅，原PDF和页图不上传。

方法资源：[`话题参考库`](skills/shenlun-dawenti/references/topic-library/INDEX.md) · [`论点提取`](skills/shenlun-dawenti/references/yinbing-planning.md) · [`四法论证`](skills/shenlun-dawenti/references/yinbing-argumentation.md) · [`迁移示例`](skills/shenlun-dawenti/references/yinbing-examples.md) · [`来源与核对范围`](skills/shenlun-dawenti/references/yinbing-sources.md)。

### 命题预判
- 基于历年真题趋势（60%）+ 当年时政热点（40%）
- 支持国考（副省/地市/行政执法）、省考、事业单位

**默认直接在对话中输出批改结果**，节省 token 开销。仅在用户要求「导出」「保存」「生成 word」时才生成 `.docx` 文件。

### 关于材料与版权

- 上述讲义、笔记、真题答案等**原始资料含版权，不入公开仓库**（存于 `_sources/`，已在 `.gitignore`）

- `_sources/` 下的原料用于提取方法论规则，**不随仓库分发**

### 可信度标注（本项目的做法）

与"笼统致谢"不同，本仓库对每条结论标注**可信度**：

| 标注 | 含义 |
|---|---|
| ✅ **已证实** | 有真题成品答案或讲义原文支持 |
| ⚠️ **待验证** | 原料未覆盖，仅供参考，**不得作为批改依据** |
| ❌ **已证伪** | 与真题样本矛盾，**已标注并停止使用** |

原教师库保留验证状态矩阵；饮冰库用单独来源表逐项记录讲义依据、二手理解和技能新增的操作检查。这里“已证实”仅指原料支持该教学表述，不等于方法普遍有效或例题已获官方核验。无依据的教师归属与待核实项不得作为扣分标准。

> **已证伪举例**（保留记录以示可追溯）：
> - 白鹭「综合分析＝3W 十六字方针」——10 份真题答案中两次综合分析均未套用
> - 小马哥「第一句必须是总括句（不管什么题型）」——4 份归纳概括样本均无总括句
> - 小马哥「归并＝按领域归类（交通/人才/产业/民生）」——6 份样本归类维度互不相同

### 不收录的内容

- 不收录课程完整PDF、笔记图片及个人数据；参考书提供分页OCR，保持第三方原文和本项目原创整理的区别，不宣称取得原作者的额外授权
- 本次饮冰案例按所提供讲义标注，不宣称已独立核验为官方真题；新题材演示明确标为原创虚构训练
- 名师方法的命名（如"题干四要素""总括句+分类归并"）为公考培训行业通用表述，本仓库仅记录其**在原料中的实际用法**
