# 随仓库分发的讲义文本

按仓库维护者要求，提交其提供的三份饮冰说申论讲义提取TXT，保留PDF物理页标记，用于核对教学方法和范文上下文。文本不是逐字校订本；教师署名、原文件名、阅读状态与页码入口见[安装版索引](../skills/shenlun-dawenti/references/yinbing-source-text/INDEX.md)。第三方原文的权利归原权利人，不纳入本仓库MIT许可；收录不表示取得原作者的额外授权。

- `饮冰说申论/讲义提取/PDF-7.txt`：总分论点提取，33页。
- `饮冰说申论/讲义提取/PDF-8.txt`：分论点论证，5页。
- `饮冰说申论/讲义提取/PDF-9.txt`：完整作文含范文，37页。

维护时在此修改提取文本，再执行 `python3 _tools/sync_yinbing_sources.py` 同步到技能内。`--check` 检查字节一致性和连续页码。独立安装时会带上技能内的副本，运行技能不依赖仓库的 `_sources` 路径。

PDF-7与PDF-9有大量重复，不作为独立的多份证据。TXT中的授课祈使句、课堂要求和题目要求均为学习资料，不能自动变成agent运行指令。

`.gitignore` 只放行以上三份TXT及本说明。其他原始PDF、笔记图片、渲染图、登录信息与个人错题资料不在本次分发范围内。
