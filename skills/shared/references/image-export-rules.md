# 申论长图导出

用户要求导出图像、长图、图片时使用；Word请求另用 `export_docx.py`。默认对话输出，不因完成作文就自动生成文件。

## 内容与样式

- 默认导出用户指定的完整回答，包括作文、选法说明、背诵迁移和原有加粗；只要正文或只要某段时按范围取舍。
- 大作文长图在正文前附**原考试题目**：考试年份/卷种、题号、分值、完整题干及字数等要求。题目和作者自拟的文章标题分开。优先从当前对话或已核对试卷取题；缺失处不编造。
- 使用白底、**黑色宋体**。正文常规宋体，加粗使用同字体的真实粗体字重；缺少粗体字重时才用轻微描边。支持中文标点避头尾，尽量保持数字及英文单词不被截断。其他系统可指定宋体文件；字体是本机依赖，不随仓库再分发。
- 默认宽1600像素、正文38像素，保留段间距、标题层级、引用与列表。链接标签保留，URL附在图末。正文不增加运行日志或实现细节。

## 调用

依赖：`python3 -m pip install -r ../shared/scripts/requirements-image.txt`（路径按当前目录调整）。

```bash
python3 ../shared/scripts/export_image.py answer.md answer.png \
  --prompt prompt.md --title "2021国考副省级申论：完整作文与方法解析"
```

仓库根目录也可用 `_tools/export_image.py`。`--font`、`--bold-font`、`--font-index`、`--bold-font-index`可指定字体文件与TTC字重索引。自动识别本机宋体；无宋体时尝试已安装的中文衬线字体，仍无合适字体则停止并说明缺少字体，不能静默用不支持中文的默认字体。

## 完成前核对

1. 正文、题干分开保存为UTF-8 Markdown，避免改写或遗漏用户指定内容。
2. 执行脚本，检查生成报告中的字体、黑色、题干是否包含及图像尺寸；需要时用 `--manifest report.json` 留存检查信息。
3. 打开PNG，检查顶部题干、正文中部和底部，确认无乱码、漏字、裁切、文字重叠，加粗可辨。脚本检查换行前后文字一致及画布边界；视觉检查仍须完成。
4. 最终给出本地PNG链接，必要时直接显示图像。排版生成的长图称“导出长图”，不冒充客户端截图。
