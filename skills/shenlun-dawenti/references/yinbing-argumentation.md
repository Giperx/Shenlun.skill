# 饮冰：四种分论点论证方法

来源：PDF-8第2–5页；PDF-9第32–37页提供方法演示。以下“适用、检查、桥梁句、迁移”是技能操作化整理；教师示范不等于官方范文。新话题完整演示见[迁移案例](yinbing-examples.md)。

## 先选法，再写段落

| 手里的证据 | 优先考虑 | 关键证明责任 |
|---|---|---|
| 论点明确，有可解释的道理或案例 | 组合论证 | 案例为何支持这个判断 |
| 已有工作、具体短板、可对应的治理措施 | 政府思维 | 怎样把短板转为政策与执行任务 |
| 原来有用，发展出现局限，可保留并改造 | 否定之否定 | 保留什么、修正什么，改后为何更合适 |
| 多次细微行动，积累机制，能力或模式变化 | 量变与质变 | 积累怎样发生，性质到底变在哪里 |

这不是高低分排序。组合论证可以严密深入，写上哲学术语也可能空泛。先做证据清单：已知事实、可作解释的机制、待证判断、拟议措施。方法缺少核心条件时，不靠编造事实补齐。

## 方法一：组合论证

**讲义骨架**（PDF-8第2–3页）：是什么＋为什么＋怎么办。“为什么”可用道理、事例、对比、引文、数据等组合，按证明需要取舍，不要求全套出现。

**成段操作**：

1. 界定分论点，直白概念可不重复解释。
2. 提供贴合论点的依据，交代与结论有关的行动和结果。
3. 补上论证桥梁：行动改变了哪个条件，如何影响目标？必要时以条件式反面比较说明边界。
4. 落到相应措施，段末回扣本段判断。

**桥梁示意**：“这项做法的价值在于……，它通过改变……降低/提升了……，因此能……。”只借逻辑功能，不照抄句式。

**检查**：删掉名言还成立吗？把案例换成别的热点，段落是否毫无变化？若是，可能只有立场和素材，没有证明。避免“因为很重要，所以要重视”的循环。没有可靠数据就用事实和机理，不为凑论证类型编数字。

讲义批评平铺、确认式论证，提示要增加推理层次；**不能据此把单个案例提升为“唯一”“必然”**，更不能仅因方法叫“组合”就降档。

## 方法二：政府思维

**讲义骨架**（PDF-8第3–4页）：必要的内涵说明→成绩清单→问题清单→政策制定与落实→目标。PDF-9的“政府思维一/二”是展开范围不同的示范，不另设第五种方法。

**成段操作**：

1. 锁定本段领域与公共目标。论点窄，成绩问题也要窄。
2. 用有依据的既有改进说明工作价值，少而准，不凭“近年来成绩斐然”填空。
3. 在同一目标内指出尚未覆盖的人群、流程或保障短板。
4. 逐项配对：问题→原因或障碍→措施→执行主体/反馈方式。视需要按政策与实施、阶段或主体展开。
5. 说明这些措施怎样把阶段性成果转成稳定成效。

**关键桥梁**：“已有改进解决了……，但尚未覆盖……，因此下一步应从……补齐，而不是仅扩大原来的数量。”

**检查**：若论点是“粮食安全支撑乡村振兴”，不能用教育、医疗、政务成绩凑三例。对策须能消解刚列出的问题；“加强重视、强化保障、完善机制”需说清保障什么、谁来执行。

公共理性意味着以公共利益、政策与实施机制思考，不意味着任何事都交给政府包办；企业、社区、个人的职责依材料而定。**成绩不足就如实简写，改用问题—对策推演或其他方法，不制造全国性成效。**

## 方法三：否定之否定

**讲义教学路径**（PDF-8第4–5页）：初始合理性→发展中的局限→扬弃、改进与升级。此处沿用授课名称描述写作路径，不把任何“正反正”都认定为完整哲学证明。

**成段操作**：

1. 初始肯定：原做法解决了什么旧问题，价值在哪里？
2. 局限显现：随着哪些条件变化，哪个具体环节暴露问题？区分理念、目标与实施方式。
3. 辩证扬弃：明确保留合理目标或有效能力，舍弃哪种片面安排，补上何种新机制。
4. 说明升级：新安排为什么能修补原缺陷，同时不失去原有价值，回扣分论点。

**关键桥梁**：“问题出在……的实施安排，而非……的目标本身；因此，应保留……，同时通过……纠正……。”

**检查**：“数字化有好处—数字化有坏处—加强数字化”缺少扬弃对象。必须落实到“保留自动筛查能力，加入人工复核与申诉纠错”这类具体变化。针对“人民至上”等正当目标，不硬编其自身坏处；有依据时分析实施偏差。违法有害做法也不为完成三步强行赋予合理性。

**与政府思维的区别**：两者都可出现成绩、问题、措施；本法突出发展中的内在矛盾和有继承的修正，政府思维突出公共工作部署与落实。不必为标签强行拆开有效推理。

第三方笔记补充了正反对照、驳斥错误认识、由浅入深揭示机制等理解（XHS-YB-01第6–13图）。可用于辅助训练，但**不把这些都称为教师独立命名的子方法，也不把一切反驳都等同于否定之否定**。哲学引入可省，实际扬弃不可省。

## 方法四：量变与质变

**讲义骨架**（PDF-8第5页）：立场→可选哲理→具体的量变实践→过渡及前后状态对比→持续做法。技能整理进一步要求解释积累机制，避免由重复行动直接宣布质变。

**成段操作**：

1. 确定待改变的系统状态：从何种能力/关系/模式，走向何种新状态？
2. 描绘可反复、可积累的小行动，交代它们积累的是什么：经验、标准、协同规则、信任或技术能力。
3. 写清积累机制：经验如何进入标准，反馈怎样改变流程，个别配合怎样变成稳定协同？必要时说明条件、配套或关键节点。
4. 对照性质差异，不能只说“更多、更快、更好”。如从逐件被动应付转为能持续识别和回应需求的服务机制。
5. 给出维持积累与纠偏的做法，回扣论点。

**关键桥梁**：“每次……不止解决当次问题，还通过……沉淀为……；当……形成稳定联动，原先依赖……的模式才有望转向……。”

**检查**：三项互不关联的措施不是积累；个人小事直接跳到国家现代化不是机制；改善效率也不天然证明根本性质变化。没有结果证据时写“有助于逐步形成/在配套条件具备时可望转向”，不说已经完成质变。允许指出当前材料只支持量的改善。

**与否定之否定的区别**：前者重持续积累及系统变化，后者重矛盾暴露及有继承的修正；不能只换哲学开头就当作改换方法。

## 改写、适配与验收

保持“观点—依据—推理—措施—回扣”相互对应，不要求每段顺序或句数完全相同。字数以用户要求为准，不能为了凑五步削弱核心证明。

改写先建立事实边界：哪些来自原文，哪些是推论，哪些是建议；不把拟议措施写成既有成绩。迁移时替换的应是具体矛盾、主体和机制，不只是话题名词。

验收时回答：

- 本段能用一句话说清在证明什么吗？
- 每条事实和过渡句怎样推进证明？有没有强于证据的结论？
- 方法的关键动作是否真实发生：有机制、有配对、有扬弃或有积累？
- 措施能解决前文提出的问题，结尾回到原分论点吗？

学习训练可采用“同一分论点换方法→同一方法换话题→诊断并改写第三方段落”。比较推理变化，不以相似句式打勾。只有用户要求方法对照才同时写四版。
