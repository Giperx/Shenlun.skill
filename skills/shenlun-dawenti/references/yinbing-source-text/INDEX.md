## 按需读取

1. 先按任务阅读方法卡。核对教师原话、步骤或例子时，再根据本表定位相关TXT，不默认加载三份全文。
2. 页标记示例：`===== PDF-7 PAGE 7 =====`。读取该标记到下一页标记之间的完整内容；跨页段落连读相邻页。
3. 可用 `rg -n "分论点优先级|优劣如何评价" PDF-7.txt` 或 `rg -n "哲学告诉我们" PDF-8.txt PDF-9.txt` 定位；无命令行时直接读取对应文本的相关页。
4. 回答时区分“讲义原文”“技能概括”“用户约定”。涉及加粗、批注位置、颜色或图像布局时，TXT不能证实版式，优先使用已核对的来源记录或用户提供的原页。
