# 饮冰方法的来源、覆盖范围与边界

整理日期：2026-11-06。用户提供三份批注版教学PDF及三篇小红书笔记。方法资料与使用者的真实作答分开，不把资料中的问题记入个人错题库。

## 一、来源层级

1. **用户提供的教师讲义**：确认教师命名方法与课堂案例的主要依据。只确认讲义呈现的内容，不等同于核验出版、作者身份或官方试题原文。
2. **第三方课堂笔记**：作者“正中一选”，注明课堂笔记与个人思考；用于补充理解、定位问题，不能把个人哲学延伸自动归给教师。
3. **技能整理与原创训练**：适用条件、证据边界、操作检查、方法选择表及新话题示例是本技能的归纳，不冒充老师逐字讲授。

题目年份、卷种、地名及结果按讲义记载，未独立核验为官方真题或标准答案。袁东评分口径另有来源，**本次资料未提供饮冰的量化评分表**，不得自行编一张。

**重复及疑点**：

**方法呈现复核（2026-11-06）**：重新核读PDF-8第4–5页和PDF-9第32–37页文字，并查看PDF-8第4–5页、PDF-9第32、35、37页渲染原页。PDF-8第4页明确“引入哲理及话题”，否定之否定示范先哲理后话题；第5页明确“明确立场，提出观点→引入哲理”。PDF-9相应示范也显式引入哲理。旧整理的“可选哲理/哲学句可省”弱化了该教学步骤，现予更正。按当前用户选定的考场写法，默认先分论点，再哲理与话题连接。

PDF-9第32–35、37页若干论证段直接点名老江剪刀、兴隆家具、明玉丝绸、E市或金教授团队，并接分析或公共认识；并非每一方法变体都点名案例。当前用户进一步明确“无论哪种论证方法，都应该提到材料例子”，据此要求有题目材料的每个分论点论证段均点实适配案例，再作机制分析和提升。区分讲义示范的事实与用户设定的统一输出要求，不声称教师所有原段均如此。

**用户补充的选材原则**：题干允许时，材料案例可来自整张试卷，优先用分论点提出自的材料；多则材料有共性时允许交叉使用。按论点与机制匹配，不限制在题干引语出处或同一案例，不要求各方法复用同一素材。

**段落框架与收束复核（2026-11-06）**：再次查看PDF-9第33、34、36页原页，结合此前已查看的第32、35、37页，核对加粗句的实际功能。第32–34页含“正如/两相对比/由此可见”“政策制定上/政策落实上”“用发展解决发展的问题”“坚持……方能……”等推进与收束；第35–37页继续呈现问题、改进与回扣。加粗既包含衔接语，也包含针对具体话题的判断，不能全部视为通用原句。新增的四法可替换模板是技能整理，保留论证功能，并按用户要求加入各法材料例证、明确的对策展开与因果回扣；不称其为教师逐字模板。

**用户明确的表达目标**：面向考场有限评阅时间，以醒目的分论点、哲理点题、逻辑衔接及措施回扣，提高内容亮点的可识别性。模板增加相应的呈现和自检办法。具体评阅时长未独立核验，不作为教师原话、官方评分规则或得分保证。

**用户补充的篇幅要求**：分论点段落尽量控制在约300字，主要压缩案例使用，保留必要分析、对策和回扣。技能将280–320字作为默认调节范围，案例通常简述为1–2句、约40–70字；这些范围是便于落实用户要求的写作参考，不归为教师原话或官方字数标准。

**用户补充的背诵迁移要求**：写好分论点论证后，提炼可背诵、可迁移的主题句、分析句、对策句或短片段，帮助备考积累与考场化用。新增迁移卡包含适用逻辑、替换要素和异主题示范；卡片为技能原创整理，不署名给教师。作为正文之外的教学附录，不挤占约300字的论证正文。

**论点提取与筛选复核（2026-11-06）**：重新完整查看PDF-7第2、7页渲染原页，并核读第2–7页提取文字。第2页区分题干充分时的同性质拆解/天然闭环与题干信息较少时的重点材料提取；第6–7页续列关系型路径、来源优先级、基本要求和质量比较。补齐第7页的客观性（显性依据）、关联度、深度与差异度，分开说明“先从哪里找”与“最终为何选”。原页来源优先级第1、2项措辞接近，未进一步定义；不擅造其差别。第5项“关系型作文”按题型适用性处理，不据编号认定其质量低。

原技能虽包含提取来源与一般质量检查，但对候选比较和多引句覆盖的操作不足。现增加“完整解读→候选来源→质量取舍→结构组织→题意回查”，避免结构先行。2021副省级“坚定信念”是技能结合用户反馈新增的校验例：它来自第一引句的含义提炼并有资料1印证，不称为教师在讲义中给出的本题标准论点；亦不将其固化为所有题目的必选项。

**用户补充的完整作文选法要求**：按各分论点与材料的契合程度逐段择法，至少一个分论点使用马哲论证；不要求四法齐用或各段方法不同。将该约定写入完整作文流程，仍保留原理点题、实质推理和事实边界，不称为教师对所有考题的统一要求。
